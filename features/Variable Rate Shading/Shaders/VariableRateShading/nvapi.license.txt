The Variable Rate Shading feature of Community Shaders is built against the NVIDIA NVAPI SDK
headers (nvapi.h, from the copy vendored in extern/Streamline-DX12/external/nvapi; upstream
https://github.com/NVIDIA/nvapi). No NVAPI binary is redistributed: the plugin loads the
nvapi64.dll that ships with the NVIDIA display driver at runtime, and only on NVIDIA GPUs.
